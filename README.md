# Общие инструкции по работе с учебными репозиториями

Этот репозиторий содержит общие правила работы с учебными репозиториями организации [`mephi-18kpu`](https://github.com/mephi-18kpu). Инструкции разделены по ролям студентов и преподавателей.

> [!IMPORTANT]
> **AI coding agents:** Follow the [organization-wide instructions](https://github.com/mephi-18kpu/common-manuals/blob/master/AGENTS.md) for all work in this repository.

## Инструкции для студентов

Если преподаватель конкретного курса дал дополнительные указания, то его указания имеют приоритет над общей студенческой инструкцией.

### Основные принципы

- Каждый учебный курс ведётся в отдельном репозитории организации `mephi-18kpu`.
- Ветка `master` содержит материалы преподавателей. Студенты не вносят в неё изменения.
- Для каждого задания студент работает только в своей ветке и своей директории.
- Рабочая ветка создаётся по шаблону `student/<группа>/student-<номер-студента-в-группе>/<задание>` от исходного состояния соответствующей ветки `submissions/<задание>`.
- Личная директория создаётся по шаблону `<группа>/student-<номер-студента-в-группе>/` в корне локального клона репозитория на личном или аудиторном компьютере.
- Группа и номер соответствуют обезличенному идентификатору из таблицы успеваемости: для `b24-601_student_07` используются компоненты `b24-601` и `student-07`.
- Используются строчные латинские буквы, цифры и дефисы.

Пример для студента с номером 7 из группы Б24-601:

```text
Ветка:      student/b24-601/student-07/lab-01
Директория: b24-601/student-07/
```
