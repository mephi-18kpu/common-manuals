# Общие инструкции для студентов

Этот репозиторий содержит общие правила работы с учебными репозиториями организации [`mephi-18kpu`](https://github.com/mephi-18kpu). Если преподаватель конкретного курса дал дополнительные указания, то его указания имеют приоритет над этой инструкцией.

## Основные принципы

- Каждый учебный курс ведётся в отдельном репозитории организации `mephi-18kpu`.
- Ветка `master` содержит материалы преподавателей. Студенты не вносят в неё изменения.
- Каждый студент работает только в своей ветке и своей директории.
- Личная ветка создаётся по шаблону: `student/<группа>/<фамилия-инициалы>`.
- Личная директория создаётся по шаблону `<группа>/<фамилия-инициалы>/` в корне локального клона репозитория на личном или аудиторном компьютере.
- Используются строчные латинские буквы, цифры и дефисы.

Пример для студента Иванова И. И. из группы Б24-601:

```text
Ветка:      student/b24-601/ivanov-ii
Директория: b24-601/ivanov-ii/
```
