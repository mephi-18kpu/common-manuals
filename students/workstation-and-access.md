# Аудиторный компьютер и аккаунт GitHub

## Аккаунт рабочего места

Для каждого аудиторного компьютера и курса используется отдельная учётная запись Windows и отдельный аккаунт GitHub. Этот аккаунт закреплён за рабочим местом и остаётся на компьютере между занятиями.

Все студенты, работающие за одним компьютером в рамках курса, используют закреплённый за ним аккаунт. При переходе на другой компьютер студент использует аккаунт нового рабочего места и продолжает работу в своей существующей ветке. Переносить аккаунт или сведения для входа с предыдущего компьютера не требуется.

Аккаунт GitHub идентифицирует компьютер, но не конкретного студента. Студент определяется по рабочей ветке `student/<группа>/student-<номер-студента-в-группе>/<задание>` и директории `<группа>/student-<номер-студента-в-группе>/`.

## Регистрация на первом занятии

Если преподаватель поручил вам участвовать в первоначальной настройке компьютера:

1. Получите у преподавателя логин и пароль служебного почтового ящика текущего рабочего места.
2. Войдите в этот почтовый ящик только в выделенной курсовой учётной записи Windows.
3. Создайте аккаунт GitHub вручную с именем, которое сообщил преподаватель.
4. Подтвердите адрес электронной почты.
5. Если GitHub требует дополнительную настройку безопасности, выполняйте её только под контролем преподавателя.
6. Сообщите преподавателю точный логин и факт завершения регистрации.

Не выбирайте произвольное имя аккаунта и не связывайте его с личной почтой, телефоном, ключом, passkey или другим личным способом восстановления. Не отправляйте пароль или коды доступа через GitHub, Pull Request, Issues либо общий чат.

## Локальная идентификация Git

В каждом клоне администратор или преподаватель задаёт технического автора коммитов, соответствующего аккаунту текущего компьютера. Например:

```bash
git config --local user.name "mephi18kpu-a220-python-pc07"
git config --local user.email "EMAIL_АККАУНТА_ИЛИ_NOREPLY"
```

Параметр `--local` означает, что настройка применяется только к текущему репозиторию. На аудиторных компьютерах параметр `--global` не используется.

Перед началом работы студент может проверить настройку:

```bash
git config --local --get user.name
git config --local --get user.email
git remote -v
```

Не изменяйте эти значения самостоятельно. Если они отсутствуют, относятся к другому компьютеру или курс не имеет доступа к репозиторию, обратитесь к преподавателю.

## Работа на другом компьютере

На новом рабочем месте не входите под аккаунтом предыдущего компьютера и не подключайте личный аккаунт GitHub. Получите сведения об удалённых ветках и подключите свою существующую ветку:

```bash
git fetch origin
git switch --track origin/student/b24-601/student-07/lab-01
```

Если ветка уже существует в локальном клоне:

```bash
git switch student/b24-601/student-07/lab-01
git pull --ff-only origin student/b24-601/student-07/lab-01
```

Замените имя ветки на выданное преподавателем. Перед изменением файлов убедитесь, что находитесь именно в своей ветке.

## Запрещённые изменения аккаунта

Студентам запрещено:

- изменять логин, пароль и адрес электронной почты аккаунта рабочего места;
- изменять двухфакторную аутентификацию и способы восстановления;
- добавлять личные SSH-ключи, passkeys, токены или приложения;
- копировать сохранённые сведения для входа;
- использовать аккаунт на личном устройстве или другом аудиторном компьютере;
- добавлять аккаунт в другие организации и команды;
- заменять аккаунт рабочего места личным аккаунтом GitHub.

Если GitHub запрашивает повторный вход, подтверждение устройства, второй фактор или восстановление аккаунта, прекратите настройку и обратитесь к преподавателю. Не пытайтесь самостоятельно сбрасывать пароль или создавать новый аккаунт взамен существующего.

## Работа вне аудитории и доступ после курса

Аккаунт рабочего места предназначен только для аудиторного компьютера. Он не предоставляет студенту персональный доступ из дома и не должен использоваться после завершения курса.

Если преподаватель разрешает работу вне аудитории или требуется доступ к архиву после курса, он отдельно сообщает допустимый порядок. Не используйте для этого данные аккаунта рабочего места.
