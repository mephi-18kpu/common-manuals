# Идентификация компьютера и личный аккаунт

## Идентификация рабочего компьютера

На рабочих компьютерах коммиты создаются от имени технической учётной записи, идентифицирующей аудиторию, компьютер и репозиторий.

Шаблон имени:

```text
<номер аудитории>-pc<номер компьютера>-<название репозитория как на GitHub>
```

Шаблон адреса:

```text
<user.name>@workstation.18kpu
```

Пример для компьютера №7 в аудитории A-220 и репозитория `2026-autumn-python-course`:

```bash
git config --local user.name "a220-pc07-2026-autumn-python-course"
git config --local user.email "a220-pc07-2026-autumn-python-course@workstation.18kpu"
```

Эти команды выполняются администратором или по указанию преподавателя при подготовке локального клона. Параметр `--local` означает, что настройка применяется только к текущему репозиторию и не затрагивает другие репозитории. На аудиторных компьютерах параметр `--global` не используется.

Студент может проверить настройку:

```bash
git config --local --get user.name
git config --local --get user.email
```

Технический автор коммита указывает, с какого рабочего места выполнена работа. Конкретный студент определяется по личной ветке и директории.

## Подключение личного аккаунта GitHub

Личный аккаунт используется для доступа к репозиторию вне рабочего компьютера и для сохранения доступа после завершения курса. Входить в личный аккаунт на общем рабочем компьютере не требуется.

### Настройка автора коммитов на личном компьютере

После клонирования учебного репозитория на личный компьютер задайте в нём свои имя и адрес электронной почты:

```bash
git config --local user.name "Ivan Ivanov"
git config --local user.email "YOUR_GITHUB_EMAIL"
```

Замените значения в примере своими данными. Для `user.email` используйте адрес, добавленный в аккаунт GitHub, либо предоставленный GitHub адрес `noreply`, указанный в настройках электронной почты аккаунта. Параметр `--global` на личном компьютере допускается, если вы хотите использовать одни данные автора во всех локальных репозиториях, однако в учебных инструкциях используется `--local`, чтобы настройка не затрагивала другие проекты.

Проверьте результат:

```bash
git config --local --get user.name
git config --local --get user.email
```

Для подключения аккаунта отправьте администратору:
- имя и фамилию;
- учебную группу;
- название курса или репозитория;
- имя пользователя GitHub без пароля и других секретных данных.

Запрос можно отправить:
1. сообщением в Telegram-чате группы или личным сообщением администратору либо преподавателю;
2. через GitHub, если вы уже состоите в организации и на странице нужной команды доступна кнопка **Request to join**;
3. другим способом, который преподаватель объявил для конкретного курса.

Если вы ещё не состоите в организации, универсальной кнопки запроса доступа к репозиторию на GitHub может не быть. В этом случае используйте Telegram. Не публикуйте ФИО, группу и другие персональные сведения в общедоступных Issues.

После обработки запроса GitHub может отправить приглашение в организацию или команду. Его необходимо принять под тем аккаунтом, имя которого было указано в запросе.

Администратору и преподавателю никогда не требуются:
- пароль от аккаунта GitHub;
- коды двухфакторной аутентификации;
- приватный SSH-ключ;
- recovery codes или токены доступа.
