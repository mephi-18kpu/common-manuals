# Правила и запрещённые действия

## Правила личной работы

- Для каждого задания работайте только в ветке `student/<группа>/student-<номер-студента-в-группе>/<задание>`.
- Размещайте результаты работы только в директории `<группа>/student-<номер-студента-в-группе>/`.
- Перед изменениями проверяйте текущую ветку командой `git branch --show-current`.
- Перед коммитом проверяйте состав изменений командами `git status`, `git diff` и `git diff --cached`.
- Используйте содержательные сообщения коммитов, по которым можно понять суть изменения.
- Не объединяйте в рабочую ветку `master` или обновившуюся ветку `submissions/<задание>` без прямого указания преподавателя.
- Для сдачи задания создавайте Pull Request из рабочей ветки в соответствующую ветку `submissions/<задание>`.
- После принятия задания не удаляйте рабочую ветку и не используйте её для следующего задания.
- При обнаружении чужих или неожиданных изменений прекратите работу и сообщите преподавателю.

## Запрещённые действия

Студентам запрещено:

- отправлять изменения непосредственно в `master`;
- отправлять изменения непосредственно в ветки `submissions/<задание>` или самостоятельно объединять направленные в них Pull Request;
- изменять, переименовывать или удалять чужие ветки;
- изменять файлы в директориях других студентов;
- создавать ветки или директории от имени другого студента;
- применять `git push --force` или `git push --force-with-lease`;
- самостоятельно переписывать опубликованную историю коммитов;
- изменять адрес удалённого репозитория, локальную идентификацию компьютера и другие параметры доступа;
- изменять логин, пароль, адрес электронной почты, двухфакторную аутентификацию, способы восстановления, ключи, токены или приложения аккаунта рабочего компьютера;
- подключать к аудиторному компьютеру личный аккаунт GitHub или использовать аккаунт рабочего компьютера на другом устройстве;
- копировать с рабочего компьютера пароли, приватные ключи, токены, recovery codes и другие учётные данные;
- изменять `.github/`, GitHub Actions, учебные материалы и служебные файлы курса без прямого указания преподавателя;
- размещать пароли, токены, приватные ключи и другие секреты;
- размещать персональные данные, не предусмотренные заданием;
- загружать чужую работу под своим именем;
- намеренно нарушать доступность репозитория или мешать работе других студентов.

Наличие технической возможности выполнить действие не означает разрешения на него. Аккаунт GitHub аудиторного компьютера используется разными студентами и идентифицирует рабочее место, а не человека. Конкретный студент определяется по рабочей ветке задания, директории и данным преподавателя.

За нарушение правил в зависимости от характера и последствий могут применяться учебные и дисциплинарные санкции в соответствии с правилами курса и университета.
